# Claude Code playground samples

The following unmodified source files and screenshots originate from [anthropics/claude-code-playground](https://github.com/anthropics/claude-code-playground/tree/main/claude-code/mods), maintained by Anthropic DevRel:

- `mods/token-weather/token-weather.mjs` and `token-weather-*.png` (3 screenshots).
- `mods/blast-radius/blast-radius.mjs` and `blast-radius-*.png` (4 screenshots).
- `mods/replay-theater/replay-theater.mjs` and `replay-theater-*.png` (4 screenshots).
- Each folder's `UPSTREAM.md` preserves the original README, limitations, and notices.

Retrieved from upstream `main` on 2026-10-13. Original source bytes and screenshot images are preserved; the catalog descriptions and creation/adaptation prompts in `MOD.md` are written for Agentmods. Source is included for reference; installation fetches the complete upstream plugin, including its manifests and hooks configuration.
